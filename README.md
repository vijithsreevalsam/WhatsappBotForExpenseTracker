# WhatsApp Expense Bot Quickstart

## How to Set Up & Add Bot to Your WhatsApp Group

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Run the Bot
```bash
npm start
```

### Step 3: Link WhatsApp Account (QR Code)
1. In your terminal, a QR code will be displayed.
2. Open **WhatsApp** on your phone (or a spare phone/eSIM with a second number).
3. Go to **Settings -> Linked Devices -> Link a Device**.
4. Point your phone camera at the terminal screen to scan the QR code.
5. Once scanned, your terminal will say: `✅ Connected successfully to WhatsApp!`.

### Step 4: Add to Group
- If using a **Secondary Number**: Open your joint expense group with your wife -> **Add Participant** -> Search for the secondary number contact and add it to the group!
- If using **Your Own Phone Number**: Link device using your main WhatsApp account. The bot will automatically listen to any group chat you are already in!
